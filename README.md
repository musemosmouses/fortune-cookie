One original fortune-cookie line for a software developer, written in the voice of a tired senior engineer.

> Legacy code is not your enemy — it is the last engineer's apology, still running in production.

## Run

```sh
node main.ts
```

This writes the entry to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program is deterministic: no network, no clock, no randomness. The entry is 95 characters, within the 120-character cap.
